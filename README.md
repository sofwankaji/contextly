# Contextly — Android APK

แอปคำศัพท์ส่วนตัวสำหรับ Android 7 ขึ้นไป ใช้ไฟล์แอปในเครื่อง ไม่โหลดหน้าเว็บจากเซิร์ฟเวอร์

## การใช้งาน

1. ดาวน์โหลด APK จากหน้า Releases แล้วติดตั้ง
2. ถ้ามีคำศัพท์ในเว็บรุ่นเดิม ให้สำรองเป็น JSON แล้วนำเข้าในหน้า ตั้งค่า ของ APK
3. เชื่อม Gemini ด้วย key ของโปรเจกต์ Free tier ที่ไม่เปิด billing เพียงครั้งเดียวบนแต่ละเครื่อง คีย์เดิมที่อยู่บนเว็บไม่ได้ถูกฝังหรือคัดลอกเข้า APK
4. เปิดแจ้งเตือนในตั้งค่า อนุญาตสิทธิ์แจ้งเตือน หากต้องการเวลาแม่นยำให้อนุญาต “นาฬิกาปลุกและการช่วยเตือน” ผ่านปุ่มเวลาแจ้งเตือน
5. กดทดสอบ แล้วออกจากแอปเพื่อทดสอบแจ้งเตือน แตะแจ้งเตือนเพื่อเปิดการ์ด

คำศัพท์และประวัติเก็บใน IndexedDB ภายในแอป คีย์ Gemini เก็บเข้ารหัสด้วย Android Keystore และเรียก Google จาก native code ไม่มี backend ของ Contextly ใน APK ไม่อัปโหลดคีย์ไป GitHub

คำที่ยังไม่ทบทวนตั้งเตือนวันที่ 3 และ 7 ไว้ล่วงหน้า การประเมินคำหรือการลบคำจะปรับรายการเตือนตามกำหนดใหม่ ตั้งล่วงหน้าได้สูงสุด 400 รายการที่ใกล้ที่สุดและเติมรายการถัดไปเมื่อเปิดแอป Android อาจเลื่อนแจ้งเตือนตามสิทธิ์ เวลาเครื่อง และโหมดประหยัดแบตเตอรี่ การบังคับหยุดแอปหรือถอนการติดตั้งอาจยกเลิกงานของแอป

## Build

ใช้ Node 24, JDK 21 และ Android SDK 36 ที่ยอมรับ license แล้ว

```sh
npm ci
npm run test:native
npm run android:sync
android/gradlew -p android assembleDebug
```

## อัปเดตหลัง push

Push เข้า `main` จะรันทดสอบ สร้าง APK ที่ลงนามด้วยคีย์เดิม และเผยแพร่ GitHub Release อัตโนมัติ แอปตรวจรุ่นล่าสุดเมื่อเปิดหรือกลับเข้าแอป (จำกัดการตรวจอัตโนมัติไม่ถี่กว่า 5 นาที) และมีปุ่มตรวจเอง เมื่อมีรุ่นใหม่ให้เปิดหน้าดาวน์โหลดและยืนยันติดตั้งบน Android ติดตั้งทับแอปเดิมเพื่อรักษาข้อมูล ห้ามเปลี่ยน app ID หรือ signing key

GitHub repository ต้องมี secrets `ANDROID_KEYSTORE_BASE64`, `ANDROID_STORE_PASSWORD`, `ANDROID_KEY_PASSWORD` สำหรับลงนาม APK เท่านั้น ห้ามใส่ Gemini key ใน secrets เหล่านี้หรือในโค้ด ให้ผู้ใช้เชื่อม key ภายในแอป

คีย์ลงนามสำคัญต่อการอัปเดต เก็บสำรองอย่างปลอดภัย อย่าคอมมิตไฟล์ keystore หรือรหัสผ่านลง Git
